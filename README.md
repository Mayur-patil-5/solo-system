# ⚔️ Solo Leveling – Player System

An interactive **Solo Leveling-inspired Player Dashboard** built using HTML, CSS, and JavaScript.

This project recreates the feeling of a futuristic RPG player status system, where users can view their hunter rank, level, health, mana, experience, physical attributes, and abilities.

## ✨ Features

- Futuristic Solo Leveling-inspired interface.
- Interactive system welcome screen.
- Player profile and hunter rank.
- Player level and experience tracking.
- HP (Health Points) and MP (Mana Points) bars.
- Experience progress bar.
- Five physical attributes:
  - Strength (STR)
  - Agility (AGI)
  - Vitality (VIT)
  - Intelligence (INT)
  - Sense (SEN)
- Interactive stat point allocation.
- Player abilities display.
- Level-up functionality.
- Glowing UI effects and animations.
- Scrollable player dashboard.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage (browser-side data persistence)
